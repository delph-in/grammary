INDRA DMRS requests (*_dmrs corpora):
  • Search for a predicate (e.g. _abon_n_rel)
  • Search for a lemma (e.g. abon)
  • X connected to Y through ARG1
  • Predicates whose ARG1 is a named entity
  • Same node as ARG1 and ARG2
  • Quantifier restriction (RSTR/H)
  • Shared-label modification (post=EQ)

  • Search for a grammar rule (cat, e.g. basic-head-opt-comp)
  • Search for a lexical type (lextype, e.g. common-noun-lex)
  • Search for a lexical entry (lexid)
  • Search for a surface form (e.g. anjing)
  • Rule with a specific n-th daughter
  • Search in the sentence text (regexp)
  • Restrict to one treebank profile
